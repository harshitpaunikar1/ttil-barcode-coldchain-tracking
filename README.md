# TTIL Barcode Cold-Chain Tracking

> **Domain:** Logistics / Cold Chain

## Overview

Mobile-first temperature monitoring system using Time Temperature Indicator Labels with Android barcode scanning, offline-first architecture, and background sync for audit compliance.

## Skills & Technologies

- Android Development
- Barcode Scanning & Decoding
- Offline-First Architecture
- SQLite Data Modeling
- API Design
